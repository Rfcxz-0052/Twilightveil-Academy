# 🎭 暮影學院 Twilightveil Academy

**製作者 Creator：林芮安（Lin Rui-An）**

一款使用 JavaScript 自製 VN Engine 開發的瀏覽器視覺小說遊戲。  
融合雙世界架構、靈力設定、光影選擇系統、台灣靈異事件與角色互動劇情。

A browser-based visual novel game developed with a custom JavaScript VN Engine.  
The game combines dual worlds, spirit powers, a light-shadow choice system, Taiwanese supernatural events, and character-driven storytelling.

# 📖 About / 關於

《暮影學院》是一款以大學校園為背景的視覺小說遊戲。

玩家將扮演一名剛入職的大學書店店員，意外覺醒靈力，進入隱藏於現實世界背後的靈學院，並探索不同靈異事件。

Twilightveil Academy is a visual novel set in a university environment.

The player takes the role of a bookstore employee who awakens spiritual abilities and discovers a hidden academy existing behind the normal world.

---

# 🎮 Game Features / 遊戲特色

## 🌗 Dual World System / 雙世界系統

白天：
普通大學校園（表世界）

夜晚：
覺醒者才能進入的靈學院（裡世界）

Day:
A normal university campus.

Night:
A hidden spirit academy accessible only to awakened individuals.


---

## ❤️ Affection System / 好感度系統

角色關係會受到玩家選擇影響。

Character relationships are affected by player decisions.

主要角色：

- 白祈 Baiqi
- 炎燼 Yanzhen
- 墨行 Moxing


---

## 🌗 Light / Shadow System

光影系統不是單純善惡值，而是代表玩家行動傾向。

The Light / Shadow system does not simply represent good or evil, but the player's approach and choices.

### Light 光

守護、理解、包容

Protection, empathy, understanding


### Shadow 影

決斷、控制、效率

Decisiveness, control, efficiency


---

## 🧩 Branching Story System / 劇情分歧系統

玩家選擇會影響：

- 角色互動
- 劇情方向
- 路線發展
- 結局

Player choices affect:

- Character interactions
- Story progression
- Routes
- Endings


---

# 🎮 VN Engine Architecture / VN 引擎架構

本作品使用自製 JavaScript VN Engine 開發。

This project is developed with a custom JavaScript VN Engine.


遊戲流程：
Story Nodes
↓
Condition DSL
↓
Engine Controller
↓
UI / Audio / Save System

---

# 🧠 Core Systems / 核心系統


## Route System / 路線系統

功能：

- 控制主線分歧
- 鎖定角色路線
- 影響後續劇情

Features:

- Controls story routes
- Locks character paths
- Affects future events


---

## Condition DSL System / 劇情判定系統

支援：

- String condition
- Function condition
- Cases branching
- Dynamic text resolving

Supports:

- 字串條件判斷
- 函式條件
- 分支系統
- 動態文字解析


---

## Affection System / 好感度系統

管理角色關係數值。

Manages character relationship values.


---

## Light Shadow System / 光影系統

控制：

- 劇情氛圍
- 選擇影響
- 世界觀傾向

Controls:

- Story atmosphere
- Choice impact
- World direction


---

## Save System / 存檔系統

保存：

- Current Node
- Text Index
- Route
- Affection
- Light Shadow


Stores:

- Current story position
- Route state
- Character values
- Choice results
