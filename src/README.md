# 暮影學院 Twilightveil Academy

**製作者 Creator：林芮安（Lin Rui-An）**

一款瀏覽器視覺小說遊戲，融合雙世界、靈力、光影選擇系統、台灣靈異事件與戀愛元素。  
A browser-based visual novel game featuring dual worlds, spirit powers, a light-shadow choice system, and Taiwanese supernatural romance.

---

## About / 關於
A visual novel project created for portfolio and job application purposes.  
本作品為視覺小說遊戲，僅用於個人作品集與求職展示。

玩家將扮演剛入職的大學書店店員，意外覺醒靈力，踏入隱藏的靈學院，並遭遇台灣各地靈異事件。  
The player takes the role of a new bookstore employee who awakens spirit powers, discovers the hidden Spirit Academy, and encounters supernatural events inspired by Taiwanese folklore.

---

## 🎮 遊戲特色 Features

- **雙世界系統**（表世界 / 裡世界）  
  Dual world system (Surface World / Inner World)

- **好感度系統**  
  Affection system with branching relationships

- **光影值系統**  
  Light-Shadow system influences story outcomes, character reactions, and moral choices

- **五行靈力設定**  (暫未確定)
  Five-element spirit power system

- **台灣靈異元素**  
  Taiwanese folklore and urban legends incorporated into story events

- **節點式劇情分歧**  
  Branching story nodes with multiple endings

- **動態事件與互動**  
  Player choices affect character behavior, story tension, and hidden events

---

## 🇹🇼 台灣特色 / Taiwanese Setting

遊戲背景以台灣大學校園與著名靈異地點為舞台，融合真實文化與都市傳說。  
The game is set in Taiwanese university campuses and notable supernatural locations, blending real culture with urban legends.

玩家可以在探索中遇見不同靈異事件，並透過光影值與好感度系統影響角色互動與戀愛發展。  
Players can encounter supernatural events during exploration, with light-shadow and affection systems affecting character interactions and romance paths.

## 🌌 世界觀 World Setting

在普通的大學校園背後，隱藏著只有覺醒者才能看見的「靈學院」。  
Behind an ordinary university campus lies a hidden Spirit Academy visible only to the awakened.

學生分為 **滅鬼派** 與 **渡鬼派**，玩家將在理念衝突與光影價值中做出選擇，影響劇情走向與結局。  
Students are divided into the **Exorcist faction** and **Salvation faction**. The protagonist must navigate conflicting ideals and light-shadow choices that shape the story and endings.

光影值系統不直接等同善惡，而是決定玩家的行為傾向：  
- **光 Light** = 守護、理解、包容 / Protection, empathy, understanding  
- **影 Shadow** = 決斷、控制、效率 / Decisiveness, control, efficiency
